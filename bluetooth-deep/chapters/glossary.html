Chapter 19

용어집 & 종합 퀴즈

이 책에 나온 용어를 한곳에 모았다. 설명 끝의 [Vol·Part·§]는 Bluetooth Core Specification 6.3에서 근거를 찾을 위치이고, Core 밖 사양(LE 오디오 프로파일 등)은 그렇게 적었다. 모르는 말이 나오면 검색하고, 링크로 해당 장에 돌아가 계산기를 다시 돌려 보자. 마지막의 종합 퀴즈는 각 장의 확인 퀴즈에서 두 문제씩 뽑았다.

참고 문헌

  • Bluetooth SIG, Bluetooth Core Specification v6.3. HTML 판 — 이 책의 모든 [Vol·Part·§] 표기의 기준.
  • Core 사양의 예제 데이터: [Vol 2] Part G(Classic 도약·접근 코드·HEC·CRC·FEC, AES-CCM, SSP, SAFER+), [Vol 3] Part H 부록 D(SMP 함수), [Vol 6] Part C(LE 패킷·채널 선택·암호화, Channel Sounding DRBG). 이 책의 계산은 모두 이 값들로 검증했다(scripts/verify-factcheck.cjs, Classic 예제는 scripts/data/partg.json). 맞지 않은 두 곳은 5장과 13장의 경고 상자에 기록했다.
  • Core 밖의 사양: Published Audio Capabilities Service v1.0.1, Audio Stream Control Service v1.0, Basic Audio Profile v1.0.1(15장).
  • 입문편: BluetoothBook — 이 책이 가정하는 기초.
