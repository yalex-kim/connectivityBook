와이파이의 모든 것

휴대폰 화면의 부채꼴 아이콘 뒤에서, 비트는 수천 개의 부반송파에 나뉘어 실리고, 안테나 여러 개가 같은 주파수에 다른 줄을 보내며, 수십 대의 기기가 서로 눈치를 보며 한 채널을 나눠 쓴다. 링크 속도 1,201 Mbps가 실제로는 왜 800쯤인지, 공유기를 옮기면 왜 빨라지는지, 비밀번호가 어떻게 암호 키가 되는지. 2.4·5·6 GHz 채널에서 OFDM, MCS, MIMO, 채널 접근, 프레임, 연결과 보안, 절전, Wi-Fi 6·7까지. IEEE 802.11을 그대로 구현한 Linux 커널과 hostapd의 공개 코드로 값을 확인하며, 직접 계산을 돌려 보고 배우는 와이파이 교과서입니다.

와이파이는 두 층과 그 위의 약속이다

IEEE 802.11이 정하는 것은 맨 아래 두 층, 전파에 비트를 싣는 물리 계층(PHY)과 공기를 나눠 쓰는 MAC입니다. 그 위의 IP·TCP와 앱은 이더넷과 똑같습니다. 연결·보안·절전 같은 약속이 MAC 위에서 동작합니다. 층을 누르면 해당 장으로 갑니다.

이 책을 읽는 방법

수식이나 전문 지식 없이도 따라올 수 있도록 만들었습니다. 각 장은 같은 흐름으로 진행됩니다.

비유회의실로 이해하기채널은 회의실, AP는 사회자, CSMA/CA는 손을 들 수 없는 회의의 눈치 규칙, 비컨은 정시 안내 방송, 묶음 전송은 택배 트럭, 절전은 경비실 택배 보관함. 익숙한 장면으로 먼저 감을 잡습니다.
