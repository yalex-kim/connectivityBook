Chapter 03

OFDM: 수천 개의 부반송파

거실에서 공유기가 보낸 전파는 휴대폰에 한 번만 도착하지 않는다. 곧장 온 전파, 천장에 튕긴 전파, 냉장고에 튕긴 전파가 수십~수백 나노초씩 늦게 겹쳐 도착한다. 메아리가 심한 강당에서 빨리 말하면 앞 단어와 뒤 단어가 뒤엉켜 알아듣지 못하는 것과 같다. 와이파이는 이 문제를 이상한 방법으로 푼다. 채널 하나를 수십~수천 개의 아주 느린 부반송파로 쪼개, 각각을 천천히 말하게 한다. 이것이 802.11a부터 모든 와이파이의 바탕인 OFDM이다.

  • 반사파가 빠른 신호에 심볼 간 간섭(ISI)을 만드는 이유와, 느린 부반송파 여러 개가 이를 피하는 원리를 안다.
  • 부반송파가 서로 겹쳐도 간섭하지 않는 직교성 조건(간격 = 1 / 심볼 길이)을 이해한다.
  • 보호 구간(GI)이 무엇을 막고 얼마를 비용으로 치르는지 계산한다.
  • 802.11a/n/ac(312.5 kHz, 3.2 µs)와 Wi-Fi 6·7(78.125 kHz, 12.8 µs)의 숫자 차이와 그 효과를 비교한다.

메아리 문제: 빨리 말할수록 뒤엉킨다

20 MHz 채널로 데이터를 보내는 가장 단순한 방법은 반송파 하나를 초당 2,000만 번 바꾸는 것이다. 심볼 하나가 50 ns다. 그런데 실내 반사파는 직접파보다 수십~수백 ns 늦게 온다. 늦게 온 앞 심볼이 다음 심볼 위에 겹쳐 내려앉는다. 이것이 심볼 간 간섭(ISI, Inter-Symbol Interference)이다. 반사가 여러 심볼에 걸쳐 번지면 수신기는 복잡한 보정(등화기)을 해야 한다.

OFDM의 발상은 반대다. 채널을 N개의 좁은 부반송파로 나누고, 각 부반송파는 N배 느리게 바꾼다. 802.11a의 20 MHz 채널은 64개로 나눠, 부반송파 하나의 심볼이 3.2 µs가 된다. 메아리 수백 ns는 3.2 µs에 비하면 작다. 게다가 심볼 앞에 짧은 보호 구간(GI, Guard Interval)을 붙여, 메아리가 도착하는 동안은 버리고 그다음부터 듣는다. 그러면 ISI가 아예 사라진다.

큰 강당에서 말하기

메아리가 0.3초 울리는 강당에서 1초에 열 단어를 말하면 앞 단어 메아리가 뒤 단어를 덮는다. 사회자는 꾀를 낸다. 64명이 각자 다른 음높이로 1초에 한 단어씩만 천천히 말하게 하고(부반송파), 단어마다 앞의 0.3초는 메아리가 가라앉도록 그냥 흘려보낸다(보호 구간). 한 사람은 느리지만 64명이 동시에 말하니 전체 속도는 그대로다.

직교성: 겹쳐도 섞이지 않는 조건

부반송파를 좁은 간격으로 촘촘히 붙이면 스펙트럼이 서로 겹친다. 그런데도 섞이지 않는 비결이 직교성(orthogonality)이다. 심볼 길이 T 동안 각 부반송파가 정수 번 진동하도록, 부반송파 간격을 Δf = 1 / T로 맞추면, 한 부반송파의 스펙트럼 꼭대기 자리에서 다른 모든 부반송파의 스펙트럼은 정확히 0이 된다. 수신기는 그 자리에서만 값을 읽는다(FFT).

부반송파 간격 Δf = 1 / TDFT    802.11a/g/n/ac: 20 MHz ÷ 64 = 312.5 kHz ↔ 3.2 µs    Wi-Fi 6·7: 20 MHz ÷ 256 = 78.125 kHz ↔ 12.8 µs
심볼 전체 길이 = TDFT + GI. 802.11a는 3.2 + 0.8 = 4.0 µs(802.11n·ac의 짧은 GI 0.4 µs면 3.6 µs). Wi-Fi 6·7은 12.8 + 0.8/1.6/3.2 = 13.6/14.4/16.0 µs.

심볼 길이 4.0·3.6 µs와 13.6·14.4·16.0 µs: Linux net/mac80211/airtime.c의 MCS_SYMBOL_TIME·HE_SYMBOL_TIME · 레거시 OFDM 심볼 4 µs: net/mac80211/util.c의 ieee80211_frame_duration()

보호 구간: 메아리를 버리는 시간

보호 구간은 공짜가 아니다. 그 시간 동안은 데이터를 싣지 않으므로 효율이 TDFT / (TDFT + GI)로 떨어진다. 802.11a의 0.8 µs GI는 4 µs 중 20%를 버린다. 그래서 802.11n·ac는 반사가 짧은 환경을 위해 0.4 µs “짧은 GI”를 두어 10% 남짓을 되찾았다. GI보다 긴 메아리가 오면 ISI가 다시 생긴다.

Wi-Fi 6는 심볼을 네 배(12.8 µs)로 늘려 이 균형을 바꿨다. 같은 0.8 µs GI라도 심볼에서 차지하는 비율이 6%로 줄고, 넓은 실외나 큰 홀처럼 메아리가 긴 곳에서는 1.6·3.2 µs GI를 골라도 손해가 크지 않다.

가장 늦은 메아리가 1.2 µs 늦게 온다. 보호 구간이 0.8 µs면 어떻게 될까?

보호 구간보다 늦은 메아리는 다음 심볼에 섞인다.

부반송파의 쓰임: 데이터, 파일럿, 빈칸

FFT 크기만큼의 부반송파가 모두 데이터를 싣는 것은 아니다. 가운데(직류 성분)와 양 끝(옆 채널과의 보호대)은 비우고, 일부는 파일럿으로 써서 알려진 값을 보내 위상·주파수가 흔들리는 것을 계속 따라간다. 나머지가 데이터 부반송파 NSD이고, 4장의 링크 속도 공식에 그대로 들어간다.

핵심 정리

  1. 빠른 단일 반송파는 실내 메아리(수십~수백 ns) 때문에 심볼 간 간섭을 겪는다. OFDM은 채널을 많은 느린 부반송파로 나눠 심볼을 길게 만든다.
  2. 부반송파 간격 = 1 / 심볼 길이일 때 직교해서 겹쳐도 섞이지 않는다. 주파수 오차는 직교성을 깨 이웃을 새어 들게 한다(ICI).
  3. 보호 구간은 메아리를 버리는 시간이다. 레거시 3.2 µs 심볼에 0.8 µs(짧은 GI 0.4 µs), Wi-Fi 6·7 12.8 µs 심볼에 0.8/1.6/3.2 µs.
  4. Wi-Fi 6·7은 간격 78.125 kHz(1/4), 심볼 12.8 µs(4배). GI 비율과 보호대 비율이 줄어 같은 폭에서 더 많이 싣는다.
  5. 데이터 부반송파 NSD: VHT 52/108/234/468, HE 234/468/980/1960, EHT 320 MHz 3920.

확인 퀴즈

OFDM이 반사파에 강한 가장 직접적인 이유는?

20 MHz 단일 반송파의 50 ns 심볼과 달리 OFDM 심볼은 3.2~12.8 µs라 수백 ns 메아리를 GI 안에 가둘 수 있다.

Wi-Fi 6의 부반송파 간격 78.125 kHz에 대응하는 심볼(DFT) 길이는?

T = 1 / Δf = 1 / 78,125 Hz = 12.8 µs. 레거시는 1 / 312,500 = 3.2 µs.

Wi-Fi 6에서 GI 0.8 µs일 때 심볼 전체 길이와 GI 효율은?

12.8 + 0.8 = 13.6 µs, 12.8 / 13.6 ≈ 94%. 레거시는 3.2 / 4.0 = 80%.

수신기가 프레임 머리에서 가장 먼저 주파수 오차를 재 보정하는 이유는?

직교성은 간격 = 1 / T가 정확할 때만 성립한다. 간격이 좁은 Wi-Fi 6는 같은 오차에 더 민감하다.

VHT 80 MHz, 256-QAM 5/6(MCS 9), 1스트림, GI 0.8 µs의 링크 속도는?

234 × 8 × 5/6 ÷ 4 µs = 390 Mb/s. 짧은 GI(3.6 µs)면 433.3 Mb/s다.
